## The entry

> My last words were "I'm fine." The autopsy disagreed.

One line, 53 characters — a dying boast undercut by the one witness
who cannot be argued with. It reads like something carved in stone,
lands on a surprise in the final two words, and is short enough to
repeat to a friend.

## How it works

`main.ts` (TypeScript, run with Node) writes that single line to
`/output/entry.txt`, after asserting it is one non-blank line of
1–150 characters. The output is fully deterministic: the same line
every run, byte for byte.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
